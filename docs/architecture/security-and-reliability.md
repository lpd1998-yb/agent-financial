# 安全与可靠性

- Status: Accepted
- Owner: Project
- Last reviewed: 2026-09-23
- Scope: 定义威胁、凭据、网络、数据保护、故障、重试、降级、恢复、告警、审计和 PDF 可用性；不定义云资源购买步骤。
- Related ADRs: ADR-0001, ADR-0003, ADR-0004

## 1. 威胁与故障模型

| 类别 | 示例 | 默认处理 |
| --- | --- | --- |
| 数据源故障 | Tushare 超时、限流、配额耗尽 | 有限重试；必要时使用旧快照并标记时间 |
| 数据质量故障 | 报告期、单位、数字或来源冲突 | 阻断受影响章节，进入检查 |
| 文档故障 | 下载、格式、解析或 OCR 失败 | 分层重试；原文可用性与解析能力分离 |
| 模型故障 | 超时、限流、Schema 错误 | 有限局部重试，显式降级 |
| 工作流故障 | 节点中断、服务重启、重复消息 | 从持久状态恢复并保持幂等 |
| 发布故障 | 飞书或 PDF 通知失败 | 报告照常保存，单独重试通知 |
| 安全故障 | 验签错误、越权、提示注入 | 拒绝请求并记录审计 |
| 成本故障 | 单任务或月度预算超限 | 暂停非必要生成 |

每个错误具有稳定错误码、归属层、是否可重试、建议动作和用户可见摘要，不能只记录“Agent 执行失败”。

## 2. 凭据和权限

- 仅允许指定飞书用户或群组访问；
- 飞书回调验证签名、时间戳和重放窗口；
- Tushare、模型、飞书、OSS 和数据库凭据不进入代码、Prompt、日志、报告或普通备份；
- 本地使用受保护环境配置，云上优先 Docker Secret 或受限配置文件，成熟后接入阿里云 KMS；
- 每个外部服务使用独立身份和最小权限；
- 生产凭据不得用于测试，轮换后旧凭据立即失效；
- Agent 工具只能访问声明的端口和参数，模型不能读取环境变量、文件系统密钥或任意 URL。

凭据值由用户在对应平台创建并通过安全渠道配置，自动化只能验证存在性和权限，不能代替实名认证或获取用户密钥。

## 3. 网络与接口安全

- 控制台和飞书 Webhook 只通过 HTTPS；
- Nginx 是唯一公网入口；
- PostgreSQL、n8n、Spring Boot 内部管理端点和 OSS Bucket 不直接公开；
- 使用安全组和主机防火墙限制端口；
- 内部 API 使用服务凭据、来源限制和最小权限；
- 状态修改接口要求身份、授权、幂等键和审计；
- 外部文档下载限制域名、协议、类型、大小、超时和重定向；
- 设置请求大小、速率和并发限制，防止资源耗尽。

## 4. 数据隐私

系统不接入持仓或券商账户。仍需保护飞书用户标识、对话、研究偏好、访问日志和反馈。

- 收集完成产品功能所需的最少数据；
- UI、日志和模型上下文默认脱敏；
- 原始消息与研究证据分开存储；
- 用户确认的偏好可查看、修改和删除；
- 向模型发送内容前移除凭据、内部地址和无关个人信息；
- 备份加密，恢复环境权限不高于生产；
- 删除请求和保留策略必须记录审计。

## 5. 幂等、重试和熔断

- 网络超时、限流和临时服务错误使用带抖动的指数退避；
- 模型 Schema 错误携带校验信息局部重试一次；
- 确定性计算错误不能通过模型重试掩盖；
- PDF 原生解析失败后才尝试 OCR；
- 引用不足时重新检索一次，再失败则降低结论强度或阻断；
- 飞书发送失败由 Outbox 重试，不重新生成报告；
- 相同幂等键不能重复创建任务、报告、通知或费用记录；
- 外部依赖连续失败时打开熔断，使用缓存或进入明确降级状态；
- 重试次数、退避、熔断状态和最后错误都必须可观察。

## 6. 降级与发布规则

| 数据级别 | 示例 | 规则 |
| --- | --- | --- |
| 核心 | 公司身份、有效财报、核心指标、当前价格/估值、asOfTime | 缺失时 `BLOCKED`，不得发布正式观点 |
| 重要 | 同行、最新财报文本、重大公告、历史估值 | 部分缺失可发布 `LIMITED`，降低证据等级 |
| 补充 | 一般新闻、次要公告、非核心行业观点 | 缺失不阻断，在附录说明 |

发布状态为 `VERIFIED`、`LIMITED`、`STALE`、`PROVISIONAL` 和 `BLOCKED`。降级必须显示缺失项、影响和恢复条件，禁止静默降级。

## 7. 任务恢复

- 每个 `ExecutionNode` 完成后持久化状态、输入版本和产物引用；
- 服务重启从最近成功节点恢复；
- Outbox 与领域状态同事务提交；
- 消费者按事件 ID 幂等；
- 失败节点可单独重试，依赖输入变化时重新运行下游节点；
- 暂停、取消、批准和人工重试记录 `HumanIntervention`；
- n8n 中断不丢失 Spring Boot 的权威任务状态；
- 已发布报告不可原地恢复或覆盖，重新执行生成新版本。

第一版恢复目标为 RPO 不超过 24 小时、RTO 为 4～8 小时；必须通过实际恢复演练确认，而不是只依据备份任务成功日志。

## 8. 告警

运行告警与股票事件提醒分开：

- 运行告警：数据库、磁盘、OSS、外部 API、任务停滞、费用、证书和备份；
- 数据质量告警：解析失败率、时间口径、来源冲突、Citation 覆盖和门禁失败；
- 安全告警：验签失败、异常访问、越权、凭据轮换和可疑下载；
- 产品告警：日周月报告未按时完成、观点长时间过期。

告警包含 traceId、影响范围、严重度、当前降级和处置入口，不在通知中暴露敏感内容。

## 9. 审计

不可变审计事件覆盖：

- Prompt、模型路由和质量规则切换；
- 人工暂停、重试、取消和批准；
- 用户反馈解释、应用和报告修订；
- 研究偏好变化；
- 数据冲突处置和历史回补；
- 权限、凭据、网络和配置变化；
- 报告发布、撤回和版本替代；
- 备份恢复和恢复演练。

系统能从审计记录复现报告所使用的数据、文档、执行节点、模型、Prompt、重试和发布原因。

## 10. PDF 长期可访问性

原始财报、公告和正式研究报告作为永久、不可变资产保存在私有 OSS。用户使用稳定应用地址：

```text
https://research.example.com/documents/{documentId}/view#page={page}
```

Spring Boot 验证身份后流式读取或生成内部短期签名，OSS 不公开。签名过期不会改变用户地址或历史报告链接。

分别处理：

- 已保存但解析失败：原文仍可查看，RAG 暂不可用；
- 解析成功但表格置信度低：原文和文本可用，相关证据降级；
- 尚未下载成功：重试下载，依赖文本结论暂不生成；
- 在线 API 或 worker 故障：已持久化资产仍可通过独立读取路径访问。

永久保存原始文件、哈希、来源、主体、类型、报告期、披露/获取时间、版本、解析文本、页码映射和处理状态。修订产生新版本；除非用户明确删除，不因缓存过期、报告更新或移出关注列表删除。

PDF 解析质量不等同于服务稳定性。分别统计原文件保存、永久查看、解析、OCR、页码映射和 RAG 入库成功率。
