# 报告体系与最新研究观点

- Status: Accepted
- Owner: Project
- Last reviewed: 2026-09-23
- Scope: 定义公司报告、日周月研究、重大事件、最新研究观点和首次研究的产品语义；不定义执行编排、存储表结构或检索实现。
- Related ADRs: ADR-0001, ADR-0002

## 1. 研究产物体系

系统维护一条统一的 `ResearchTimeline`，所有研究产物共享版本化的数据、计算和证据，不分别保存互相矛盾的事实副本。

| 产物 | 主要用途 | 时间尺度 |
| --- | --- | --- |
| `ResearchBaseline` | 完整研究逻辑与比较基线 | 月度或重大变化后 |
| `DailyResearchSnapshot` | 保存每日结构化状态 | 每个交易日 |
| `DailyChangeBrief` | 说明具有实质意义的日变化 | 按变化生成 |
| Weekly Report | 聚合趋势和下周观察项 | 每周 |
| Monthly Report | 更新完整研究逻辑 | 每月 |
| Event Alert | 提醒已经验证的重大事件 | 事件触发 |
| `CurrentInvestmentView` | 回答“现在怎么看” | 查询时动态组装 |
| PDF Report | 永久、可引用的报告版本 | 每次正式发布 |

投资观点的依据始终是底层结构化数据、确定性计算和文档证据。日报、周报和月报是同一研究资产在不同时间尺度下的视图，不是彼此的证据来源。

## 2. 公司研究报告结构

完整报告由固定研究问题树驱动。Agent 为每个问题收集结构化数据、计算结果和文档证据，最后再综合表达，不能用一个大 Prompt 自由补全文本。

### 2.1 分析口径

- 公司名称、证券代码和适用行业模板；
- 分析截止时间、最新可用财报期和报告生成时间；
- 数据版本、完整度、缺口和降级情况；
- 模型、Prompt、工具和证据版本。

### 2.2 结论摘要

- 当前经营状态和估值状态；
- 最重要的积极因素、风险和不确定性；
- 当前研究状态与观察建议；
- 结论置信度、证据强度和已知限制。

### 2.3 公司与商业模式

说明盈利来源、收入与利润构成、行业阶段、竞争优势、周期属性和关键驱动因素。

### 2.4 财务质量

覆盖营收、利润、ROE、毛利率、净利率的三至五年趋势，经营现金流与净利润匹配度，负债、商誉、应收和存货风险，以及最新季度的趋势变化。

### 2.5 增长质量

区分销量、价格、并购、会计变化和一次性收益，评价增长稳定性与可持续性，并引用管理层解释和可验证依据。

### 2.6 估值分析

展示 PE、PB、股息率等适用指标、自身历史分位、同行比较、盈利增长支撑程度，以及不同假设下的合理估值区间。估值区间是研究假设，不是目标价承诺。

### 2.7 同行对比

比较盈利能力、成长性、财务稳健性、估值和竞争位置。同行由行业规则产生，模型只能辅助检查，不可无依据选择有利样本。

### 2.8 近期事件

覆盖财报、业绩预告、公告、管理层变化、监管、诉讼、减持、行业政策和可能影响未来数月的催化或风险。

### 2.9 风险与证伪条件

明确当前判断依赖的假设、会使判断失效的数据变化、下次财报的观察项和尚不能量化的风险。

### 2.10 结论与观察计划

分别评价经营质量、成长质量、财务稳健性、估值吸引力、风险水平和证据完整度，说明下次评估时间或触发条件。第一版不生成缺乏解释的单一投资总分，也不输出仓位比例和确定性买卖指令。

### 2.11 证据附录

列出指标口径、Tushare 数据与时间、财报和公告引用、可靠新闻引用，以及缺失数据与降级说明。重要结论必须能定位到结构化事实、计算过程或原文页码。

### 2.12 行业模板

第一阶段完整支持非金融 A 股。银行、保险和券商使用后续独立模板；模板可以改变指标、规则和问题树，但不改变报告、任务、证据和版本的核心模型。

### 2.13 生成职责

| 工作 | 责任方 |
| --- | --- |
| 证券识别、任务规划 | 大模型建议，规则校验 |
| 财务、行情、估值数据获取 | Tushare Tool |
| 增长率、分位数、同行排名 | Java 确定性计算 |
| 财报解释和风险证据检索 | RAG |
| 同行候选 | 行业规则生成，模型辅助检查 |
| 综合判断与叙述 | 大模型 |
| 数字、引用和完整性校验 | Java 校验器与模型检查 |
| 发布与通知 | Spring Boot、n8n、飞书 |

## 3. 日报、周报和月报

### 3.1 日报：观察变化

每个交易日收盘后，为关注股票生成 `DailyResearchSnapshot`，保存价格与估值变化、新公告和新闻、新风险或催化、相对上一个交易日及研究基线的变化，以及是否需要重建完整基线。

没有实质变化时只保存结构化快照，不生成重复长文，也不为填充内容调用大模型。飞书可以把全部关注股票合并成简短日报。

默认时间为每个交易日 22:30；非交易日没有新增内容时不生成空报告。

### 3.2 周报：观察趋势

周报聚合一周内的每日变化，回答重要变化、估值区域迁移、风险增强或减弱、趋势与噪声、下周观察对象，以及需要重新完整分析的股票。

周报是关注列表级趋势总结，不是七份日报拼接。默认时间为每周日 20:00。

### 3.3 月报：更新研究逻辑

月报是完整研究基线，覆盖商业模式、财务趋势、最新季度、现金流与资产负债质量、估值、同行、累计事件、风险、证伪条件和下月观察项。

默认在月末后的第一个周日生成。新财报、业绩预告或重大风险可以提前触发基线重建，无需等待月末。具体调度时间由 n8n 配置，不写入核心业务代码。

## 4. 重大事件提醒

重大事件独立于三级报告：

| 等级 | 示例 | 通知 |
| --- | --- | --- |
| 高 | 立案调查、退市风险、重大违约、业绩大幅修正、重大资产风险 | 原始证据验证后立即提醒 |
| 中 | 财报、业绩预告、分红、回购、减持、重大合同 | 当日汇总 |
| 低 | 常规公告、一般行业新闻、重复报道 | 纳入日报或周报 |

系统先按文档哈希和事件指纹去重，再以公告类型和关键词初筛，最后由模型做结构化分类。高等级事件必须绑定原始公告或可靠新闻，不能只根据标题或模型判断触发。

## 5. 最新投资分析观点

`CurrentInvestmentView` 用于回答“现在怎么看这只股票”。它是非个性化研究辅助，不读取持仓、不输出仓位比例和确定性买卖指令。

```text
最近研究基线（月报或首次完整研究）
    + 最近周报
    + 最新日报与重大事件
    + 查询时最新价格、估值和公告
    = CurrentInvestmentView
```

观点展示经营质量、成长质量、财务稳健性、估值吸引力、风险水平、证据强度和结论新鲜度。允许的研究状态为：

- 值得深入关注；
- 等待更好估值；
- 等待基本面验证；
- 风险上升；
- 暂时回避研究；
- 信息不足。

这些状态表达研究优先级和观察条件，不代表收益保证。

## 6. 观点变化解释

每次变化必须保留前后版本并解释：

- 上次观点与当前观点；
- 导致变化的数据、公告、证据或事件；
- 哪些原有假设已经失效；
- 哪些维度未变化；
- 下一次需要验证的指标、披露或事件。

变化历史同时进入模型、Prompt、RAG 和规则评测数据集，但不能以未来股价倒推改写当时的判断。

## 7. 首次研究与冷启动

股票首次查询且没有任何日、周、月报时，系统创建 `BootstrapResearchTask`，直接以底层数据和证据建立基线：

1. 解析证券、公司和行业身份；
2. 获取三至五年财务、行情和估值历史；
3. 选择同行并获取对比数据；
4. 获取最新财报、公告和新闻；
5. 下载并解析必要 PDF，完成证据入库；
6. 执行确定性计算和证据检索；
7. 检查最低数据与证据门槛；
8. 生成 `InitialResearchBaseline`；
9. 生成首个 `CurrentInvestmentView`。

`InitialResearchBaseline` 与月度完整报告深度相同，不需要等待月末。

冷启动生命周期为：

```text
UNINITIALIZED → BOOTSTRAPPING → PROVISIONAL → VERIFIED
```

异常或过期分支为：

```text
BOOTSTRAPPING → INSUFFICIENT_EVIDENCE
BOOTSTRAPPING → FAILED
VERIFIED → STALE → REFRESHING
```

`PROVISIONAL` 只提供明确标记的事实和估值观察，不给出强研究结论。主体、财务、最新财报、估值历史、同行、重大公告、数字和引用均通过最低门槛后才进入 `VERIFIED`。证据不足时只返回事实摘要，不能让模型补齐信息。

## 8. 关注列表预热

股票加入关注列表后立即在后台执行冷启动，提前建立研究基线和最新观点。未关注且从未分析的股票在首次查询时现场启动，飞书先返回进度，完成后主动通知。

关注列表股票使用最近有效基线加增量变化加速查询；若新财报或重大事件尚未处理，原观点必须标记为 `STALE`。

## 9. PDF 研究资产

正式日报、周报、月报和完整公司研究可以生成网页报告与 PDF。PDF 具有：

- 永久对象标识和不可变版本；
- 长期可访问入口；
- 引用到页码、表格或段落的定位信息；
- 与报告、数据、证据、模型和 Prompt 版本的关联；
- 原始报告不可覆盖，修订生成新 PDF；
- 在线生成服务故障不影响已经持久化的 PDF 访问。

访问控制、对象存储和恢复由 [安全与可靠性](../architecture/security-and-reliability.md) 定义。

## 10. 内容质量与风险表达

- 所有精确数字必须来自结构化数据或确定性计算；
- 当前行情和估值必须在查询时刷新或展示明确截止时间；
- 文本结论必须引用足够证据，证据不足时降级为事实摘要；
- 历史分析不得使用截止时间之后的披露；
- 报告必须列出缺失数据、降级、置信度和证伪条件；
- 研究状态不能伪装成个性化投资建议或收益承诺；
- 不因用户认同度低而篡改客观事实；
- 报告质量门禁失败时不得发布正式观点。

用户可见交互见 [用户体验与交互](user-experience.md)，反馈和修订规则见 [反馈与报告修订](feedback-and-revision.md)。
