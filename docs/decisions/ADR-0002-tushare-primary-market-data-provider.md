# ADR-0002：Tushare 作为第一版主要市场数据源

- Status: Accepted
- Date: 2026-09-23
- Deciders: Project
- Supersedes: None

## Context

第一版面向个人使用的 A 股研究，需要公司、证券、行业、财务、行情、估值、公告和新闻能力。同时接入多个平台会提前引入口径映射、去重、供应商冲突和额外账号成本，影响 M0–M4 主链路学习。

正式财报和公告原文仍有自己的法定披露来源，任何聚合平台都不能取代原始文件的证据地位。

## Decision

第一版使用 Tushare 作为唯一结构化市场数据平台：

- 通过 `MarketDataProvider`、`DisclosureProvider` 和 `NewsProvider` 端口接入；
- 结构化财务、行情和估值数据保存来源、版本和时间；
- Tushare 的公告链接用于发现和关联，正式报告引用永久保存的原始披露文件；
- 新闻只作为事件线索和分级证据，不能直接成为公司事实；
- 购买 5000 积分、公告和新闻权限之前在 M0/M1 验证接口、频率和字段覆盖。

## Alternatives

### 交易所和公司官网直连

原始性最强，但下载、反爬、格式、历史补齐和标准化成本高。它们保留为证据权威来源，不作为第一版所有结构化数据的统一 API。

### 多商业数据平台并行

可以交叉验证和降低单一供应商风险，但会增加费用、口径冲突和维护面。第一版不采用，后续按数据缺口和稳定性评测引入。

### 非正式抓取库

适合探索，不适合作为长期权威依赖；接口稳定性、授权和数据解释不足，未采用。

## Consequences

正面结果：

- 快速建立 A 股结构化数据闭环；
- 账号、成本和适配器数量可控；
- 领域通过端口与供应商解耦。

风险与代价：

- 受 Tushare 权限、配额、字段和服务稳定性影响；
- 必须保存版本并实现限流、缓存和降级；
- 重要披露仍需下载原始 PDF；
- 如果后续引入第二数据源，需要建立字段口径和冲突解决规则。
