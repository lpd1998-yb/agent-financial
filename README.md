# Agent Financial

面向个人使用的 A 股中长期研究 Agent。系统计划使用飞书作为主要对话入口，以 Spring Boot、Spring AI 和 n8n 组成受控 Agent 工作流，并结合 Tushare、RAG、日周月报告、最新研究观点和 AI 研究控制台。

## 项目状态

当前处于设计完成、等待实施规划阶段。首轮实施最低目标为完成 M4：持续研究与飞书产品体验。
